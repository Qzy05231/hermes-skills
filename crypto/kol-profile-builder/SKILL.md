# KOL Profile Builder

一键生成加密KOL的结构化用户画像。

## When to Use

- 用户说「分析一下 @用户名」「给这个KOL做画像」「这个博主怎么样」
- 想要了解某个KOL的身份背景和可信度
- 追踪KOL追踪名单中的新成员
- 评估某个KOL是否值得长期关注

## Workflow

### Step 1: 采集原始数据

使用浏览器（推荐）或 xurl/xclaw 采集以下数据：

**必须字段：**
- 显示名称、用户名
- Bio / 个人简介
- 关注数、粉丝数、帖子数
- 加入时间
- 认证类型（蓝标/金标/灰标）
- 最近 10-20 条推文内容 + 互动数据（点赞/转发/回复/浏览）
- 置顶推文

**可选增强数据（如果可获取）：**
- 项目关联（bio中的链接、提及的项目）
- 标志性出圈推文
- 社区评价/媒体报道

### Step 2: 分析维度

#### 1️⃣ 身份标签
- **开发者 / 研究员 / 投资人 / 交易员 / 项目方 / 媒体 / OG**
- 关联项目名称
- 技术背景 vs 市场背景

#### 2️⃣ 影响力数据
| 指标 | 评估标准 |
|------|----------|
| < 1万粉 | 微型KOL / 早期 |
| 1万-5万 | 初级影响力 |
| 5万-20万 | 中腰部（@0xCygaar 级别） |
| 20万-100万 | 头部 |
| > 100万 | 顶流 |

**互动率评估：**
- 置顶推文点赞 / 粉丝数 比值
- 近10条推文平均点赞
- 是否有病毒式传播推文（点赞>1万）

#### 3️⃣ 关注领域
按主题分类推文内容占比：
- L2/基础设施、DeFi、NFT、AI×Crypto、GameFi、监管政策、宏观经济、土狗/Meme、技术开发
- 每个领域标注主/次

#### 4️⃣ 内容风格矩阵
| 维度 | 选项 |
|------|------|
| 技术深度 | ⭐ 小白友好 ↔ ⭐⭐⭐⭐⭐ 硬核技术 |
| 发布频率 | 每日多更 / 每日1条 / 不定期 |
| 语言 | 英文 / 中文 / 双语 |
| 内容形式 | 长线程 / 短推 / 图文 / 视频 |
| 情感基调 | 严肃分析 / 幽默段子 / 喊单激动 / 中立客观 |

#### 5️⃣ 核心观点 & 立场
- 持续输出的主题（3-5条）
- 明确支持/反对的立场
- 是否有FUD/喊单倾向

#### 6️⃣ 可靠度评分 (1-5⭐)
| 维度 | 说明 |
|------|------|
| **技术深度** | 是否真懂技术，还是包装 |
| **信息准确度** | 过往预测/分析的准确率 |
| **诚信度** | 是否推广过rug项目，有没有利益冲突声明 |
| **实战价值** | 信息对投资/研究是否有用 |
| **独立性** | 是否客观，还是纯项目PR |

### Step 4: 数据获取方法

**方法A — 浏览器（推荐，数据最完整）：**
```javascript
// 在 x.com/username 页面控制台运行获取资料
// 1. 导航到 https://x.com/username
// 2. 从页面元素中提取信息
```

**方法B — xurl（无需登录）：**
```bash
xurl /2/users/by/username/USERNAME --auth oauth2
xurl /2/users/by/username/USERNAME?user.fields=description,public_metrics,created_at,profile_image_url,verified_type --auth oauth2
```

**方法C — xclaw（如果API可用）：**
```bash
curl -s -x http://127.0.0.1:7897 "https://api.xclaw.ai/v2/tweets?username=USERNAME&limit=20" \
  -H "x-api-key: $XCLAW_API_KEY"
```

## Pitfalls

1. **xclaw API不稳定** — 经常返回404，备选方案是浏览器直接抓
2. **X登录墙** — 未登录状态下只能看到3-5条推文，限制在profile页能看到的更多
3. **数据时效** — 互动数据是即时的，画像应标注数据采集时间
4. **主观判断** — 可靠度评分是主观评估，标注信息来源
5. **AI生成的推文内容** — 部分KOL可能用AI代写，注意区分
